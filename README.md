# Sonar Poller Docker

Docker image for running Sonar Pollers.

## Included

- Ubuntu 24.04
- PHP 8.3 / PHP-FPM
- NGINX
- Supervisor
- SNMP
- fping
- Sonar Poller

Supervisor manages NGINX, PHP-FPM, and the poller process.

## Configuration

See the Sonar Poller documentation for configuration and usage.
